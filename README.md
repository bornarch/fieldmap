# 강남·서초 위반건축물 지도 · 현장용

휴대폰 GPS로 내 위치를 보면서 후보 건물을 확인하고, 배포 완료를 체크하는 지도입니다.
후보 건물·대장 확인 등급·배포 체크는 구글시트에 있고, 지도는 1분마다 시트와 동기화합니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| index.html | 지도 페이지 |
| config.js | 구글시트 웹 앱 주소 (설치할 때 한 번 입력) |
| map.json | 건물 외곽선·위반 여부·동 (공개 자료, 후보 정보 없음) |
| roads.json | 도로중심선 (국토지리정보원 연속수치지형도 1:5,000) |
| exits.json | 지하철 출구 (© OpenStreetMap 기여자, ODbL) |

후보 주소·소유자 거주·위반 상세는 이 저장소에 없습니다. 접속 비밀번호를 넣은 사람에게만 구글시트가 보내 줍니다.

## 등급을 고치거나 후보를 추가할 때

구글시트 '후보' 시트를 고치면 1분 안에 모든 지도에 반영됩니다.
붙여넣기로 여러 줄을 한꺼번에 바꿨는데 반영이 안 되면, 시트 상단 메뉴 **지도 → 후보 시트를 지도에 다시 보내기**를 누르세요.
'건물번호'(지도 속 건물 위치)와 '키'는 고치지 마세요. 새 후보를 추가할 때는 Claude에게 요청하면 건물번호를 찾아 줍니다.

## 비밀번호를 바꿀 때

구글시트 '설정' 시트 B1 칸을 바꾸면 됩니다. 직원들 휴대폰에서 새 비밀번호를 다시 넣으라는 창이 뜹니다.

## 지도 좌표

건물 좌표는 EPSG:5186(중부원점 GRS80 TM)에서 원점 (198237.46, 548315.13)을 빼고 y축을 뒤집은 1m 단위 값입니다.
